# Contributing

Thanks for helping improve Space Invader Game.

## Good contributions

- Bug fixes
- Gameplay improvements
- Performance or code-quality improvements
- Documentation fixes
- Tests for game logic
- New roadmap features

## Guidelines

1. Keep changes focused.
2. Do not remove or replace bundled assets without checking their licensing.
3. Test `python game.py` locally when your environment supports Pygame.
4. Keep dependency changes explicit in `requirements.txt`.
5. Explain user-visible gameplay changes in your pull request.
